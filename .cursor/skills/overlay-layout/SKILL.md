# Раскладка оверлея

## Перед правкой

Прочитай [references/anchors.md](references/anchors.md).

Если ширина холста или прямоугольники равны нулю, остановись и попроси скриншот интерфейса в разрешении стрима. Числа не выдумывай.

## Страница

- Фон прозрачный, чтобы в OBS был виден захват игры.
- Рамка миникарты и рамка панели героя — абсолютные блоки по прямоугольникам из якорей.
- Внутренность рамки прозрачная: игра внутри неё видна.
- Центр холста без декора.
- Адрес для OBS — локальный сервер разработки или предпросмотра, не `file://`.

## Анимация

Класс или состояние вешается на рамку, когда команда `play` принята модулем состояния. Снятие состояния по окончании анимации — часть того же поведения и покрывается тестом.
