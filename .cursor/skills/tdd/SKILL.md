# TDD

## Цикл

- [ ] Есть одно предложение: что меняется для пользователя или для команды.
- [ ] Написан один падающий тест.
- [ ] `npm test` упал из-за отсутствующего поведения, не из-за опечатки.
- [ ] Написан минимальный код.
- [ ] `npm test` прошёл. Вывод есть в ответе.

Новый цикл на каждое следующее поведение. Не копить несколько новых ожиданий в одном тесте.

## Форма теста команды

```ts
import { describe, expect, it } from "vitest";
import { applyCommand, createState } from "./overlay-state";

describe("applyCommand", () => {
  it("проигрывает известную анимацию один раз", () => {
    const state = applyCommand(createState(), { type: "play", name: "objective" });
    expect(state.playing).toBe("objective");
  });
});
```

Дальше отдельные тесты: повтор во время проигрывания игнорируется; пустое и неизвестное имя возвращают прежнее состояние.

## Чего не делать

Не проверять цвет пикселя и не снимать скриншот всей страницы как тест. Картинку смотрят в браузере и в OBS, как написано в `AGENTS.md`.
