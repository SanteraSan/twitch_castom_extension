# Оверлей Heroes of the Storm для OBS

Прозрачная страница поверх захвата игры. В кадре две рамки: вокруг миникарты и вокруг портрета с панелью способностей. Позже страница проигрывает анимацию по короткой команде. Зритель эту страницу не нажимает: OBS впечатывает её в видео.

Разработка и эфир на Windows. Страница одна и та же.

## Границы первой фазы

- Исходники в `src/`, тесты рядом: `*.test.ts`.
- Стек: Node.js LTS, TypeScript, Vite, Vitest. Страницу OBS открывает по `http://127.0.0.1`, не как файл с диска.
- Фон страницы прозрачный. Декор не закрывает центр кадра.
- Якоря берутся из `.cursor/skills/overlay-layout/references/anchors.md`. Пока там нет чисел со скриншота, рамки не позиционировать наугад.
- Команда анимации не знает, кто её прислал.

## Вне этой работы

- Расширение Twitch, Developer Rig, кнопки зрителя.
- Запросы страницы к Twitch и любые секреты в репозитории.
- Чтение памяти игры и разбор реплея ради координат, которых нет на экране.
- Установщик игры, Lutris, Wine.

События канала Twitch и наблюдатель за прямоугольником экрана начинаются отдельными фазами из `PLAN.md`.

## Контракт команды

```ts
type OverlayCommand = { type: "play"; name: string };
```

Поведение, которое фиксируют тесты:

- известное имя проигрывает анимацию один раз;
- повтор того же имени, пока анимация не кончилась, игнорируется;
- пустое или неизвестное имя не меняет страницу и не бросает исключение.

## Как проверить

1. `npm test` проходит.
2. `npm run dev` открывает прозрачную страницу в браузере.
3. Источник «Браузер» в OBS смотрит на тот же адрес, фон сцены сквозь страницу виден.
4. Рамки сидят на миникарте и на панели героя по скриншоту пользователя.

Задачу нельзя называть готовой, пока тест не запущен, а картинка не открыта.

## Роли

Пишет код основной агент в чате. Отдельного агента-программиста нет: так виден дифф.

| Роль | Файл | Когда |
|---|---|---|
| planner | `.cursor/agents/planner.md` | Новая фича или больше двух файлов. Возвращает план, исходники не пишет. |
| style-reviewer | `.cursor/agents/style-reviewer.md` | После правок кода. Только правило code-style. |
| security-reviewer | `.cursor/agents/security-reviewer.md` | После правок кода. Только правило security. |
| verifier | `.cursor/agents/verifier.md` | Перед словами «готово». Запускает `npm test` и сверяет фазу из `PLAN.md`. |

Если ревьюеры расходятся, побеждает текст правила. Если правило молчит, агент спрашивает пользователя и не дописывает вкус от себя.
