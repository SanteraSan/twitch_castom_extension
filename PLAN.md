# План разработки

Оверлей Heroes of the Storm: страница для OBS, потом реакция на экран, потом события канала, и только после этого кнопки зрителя в расширении Twitch. Этот файл — порядок работ. Что нельзя делать в первой фазе, написано в `AGENTS.md`.

Папку целиком, вместе со скрытым каталогом `.cursor`, нужно открыть в Cursor на Windows. Правила, роли и скиллы подхватятся сами.

## Фазы

### 1. Каркас и одна команда

Поставить Node.js LTS. Создать проект Vite + TypeScript + Vitest так, чтобы `npm test` и `npm run dev` существовали.

Первая фича по TDD: модуль принимает `OverlayCommand`. Сначала падающий тест из контракта в `AGENTS.md`, потом реализация. Страница пока может быть пустой и прозрачной.

Готово, когда `npm test` зелёный и в браузере открывается пустая прозрачная страница.

### 2. Страница в OBS

Подключить страницу источником «Браузер» на адрес локального сервера. В свойствах источника включить свой CSS не нужно: прозрачность задаёт сама страница. Сквозь неё виден рабочий стол или сцена.

Готово, когда в превью OBS нет белого прямоугольника.

### 3. Две рамки

Нужен скриншот интерфейса Heroes of the Storm в том разрешении, в котором идёт стрим. По нему заполняется `.cursor/skills/overlay-layout/references/anchors.md`: холст, миникарта, панель героя.

Рамки рисуются по этим числам. Центр кадра остаётся пустым. Пока чисел нет, фаза не начинается.

Готово, когда на скриншоте, подложенном под страницу, обе рамки сидят на своих местах.

### 4. Одна анимация

Команда `{ type: "play", name: "objective" }` запускает короткую вспышку рамки. Повтор во время вспышки игнорируется. Имя для проверки можно отправить из теста и временной кнопки, которую не видно в эфире.

Наблюдатель за прямоугольником экрана (объявление объекта, смерть, доступный талант) делается после того, как эта команда уже работает. Он только присылает ту же команду. Какой момент оживлять первым, решает пользователь.

### 5. События канала

Отдельная локальная программа, не страница OBS. Twitch CLI и приложение на dev.twitch.tv. Секрет остаётся в этой программе. На страницу уходит опять только `OverlayCommand`.

### 6. Кнопки зрителя

Расширение Twitch поверх плеера. Нажатие зрителя превращается в ту же команду для страницы OBS. Рамки из OBS в расширение не переносятся: иначе они пропадут из записи.

## Как ставить задачу агенту

Один чат — одна фаза. Режим Agent. В новом чате писать так:

Фаза 1:

> Сделай каркас из PLAN.md, фаза 1. Следуй скиллу tdd. Контракт команды бери из AGENTS.md. Twitch, игру и наблюдатель экрана не трогай. В конце запусти npm test и покажи вывод.

Фаза 2:

> Подключи прозрачную страницу так, чтобы её открыл источник «Браузер» в OBS по адресу локального сервера. Белый фон недопустим. Тесты не ломай. Запусти npm test.

Фаза 3, после того как в `anchors.md` внесены числа:

> По якорям из скилла overlay-layout нарисуй две рамки. Центр кадра не закрывай. Сначала тест на то, что рамки читают якоря, потом вёрстка. Запусти npm test.

Фаза 4:

> Добавь анимацию на команду play с именем objective. Повтор во время анимации игнорируй. Сначала падающие тесты, потом код. Наблюдатель экрана не пиши.

Перед «готово» в том же чате:

> Запусти verifier. Параллельно style-reviewer и security-reviewer. Если спорят, побеждает правило. Если правила нет, спроси меня.

## Что поставить на Windows до фазы 1

- Cursor и эта папка.
- Node.js LTS.
- OBS Studio. Источник «Браузер» в официальной сборке для Windows уже есть.
- Heroes of the Storm как обычная игра, не через Lutris.

Twitch CLI, Glaxnimate и Inkscape к фазе 1 не относятся. Glaxnimate нужен в день, когда появятся готовые картинки для вспышки. До этого вспышка делается на CSS.
